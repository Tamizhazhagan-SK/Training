Vehicle Utils¶

Vehicle Factory Module.

This module provides factory functions to instantiate different types of vehicles (Standard, Electric, and Hybrid) based on input data dictionaries.

utils.app.create_vehicle(vehicle_data)¶

Create and return a vehicle instance based on the provided data dictionary.

Parameters:

vehicle_data (dict) – A dictionary containing vehicle details such as vin, model, and optionally battery_kwh and fuel_type.

Returns:

An instance of Vehicle, ElectricVehicle, or HybridVehicle depending on the supplied parameters.

Return type:

Vehicle

Example

>>> data = {"vin": "123", "model": "Tesla", "battery_kwh": 75}
>>> create_vehicle(data)
<ElectricVehicle: Tesla>
